# Changelog

## 2.1.0 (2026-10-16)

- **Blank**: a blank panel with your own text. Drag either edge, or use the context menu, to set the width from 1 to 64 HP. The context menu edits the text (Shift+Enter for a new line), its size, font and direction (horizontal, rotated, or stacked vertically for Chinese and Japanese), and turns the screws on or off. Follows Rack's light/dark panel setting.

## 2.0.0 (2026-10-01)

First version.

- **SEQ-101**: four tracks of indexed steps with patterns and loops; per-track voltage tables with built-in and user reference tables; smoothing, ratchet, trigger mode, clock division and multiplication; EDIT / FOLLOW / HOLD modes with quantized COMMIT; MATH transforms; 16 snapshots; quantized reset; undo/redo.
- **SEQ-101ext** expander: five-operation transforms and rotoinversion; 99 parts with FIRST / LAST / USER transitions and CV selection; 16 groups with Euclidean selection and an X/Y/Z modulation bus (slopes and HIGH/LOW transforms); alter, step and real-time recording with pass-thru; 127 snapshot slots; MIDI file import.
- Light and dark panels.
