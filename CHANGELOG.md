# Changelog

## 2.0.0 (unreleased)

First version.

- **Indexed Quad Sequencer**: four tracks of indexed steps with patterns and loops; per-track voltage tables with built-in and user reference tables; smoothing, ratchet, trigger mode, clock division and multiplication; EDIT / FOLLOW / HOLD modes with quantized COMMIT; MATH transforms; 16 snapshots; quantized reset; undo/redo.
- **Sequencer Controller** expander: five-operation transforms and rotoinversion; 99 parts with FIRST / LAST / USER transitions and CV selection; 16 groups with Euclidean selection and an X/Y/Z modulation bus (slopes and HIGH/LOW transforms); alter, step and real-time recording with pass-thru; 127 snapshot slots; MIDI file import.
- Light and dark panels.
